# Student Project Tracker — Cloud Variant

## Overview

This project is a hands-on web application development cloud variant.
It adapts the original Student Project Tracker to use a cloud-hosted
PostgreSQL database.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express
- Hosting: Vercel
- Database: Supabase PostgreSQL
